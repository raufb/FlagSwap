Groups are named bundles of flag values. Enable a group to apply all its flags at once. Domains can also activate a group on specific hosts.

Per-domain profiles switch automatically based on the current tab's host — no manual switching. Suffix matches the domain and all its subdomains (e.g. example.com matches app.example.com). Exact matches one host. Glob allows * wildcards.

Container profiles scope overrides to a Firefox container (contextual identity). Two tabs on the same site but in different containers resolve to different flag values — set a flag true in one, false in another, side by side. Merge layers on top of everything else (highest precedence). Solo isolates: only this container's flags are overridden; all others fall back to the site's real values.
