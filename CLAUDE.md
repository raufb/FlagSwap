FlagSwap is a browser plugin that allows users (mainly QA engineers) to swap feature flags set using software like LaunchDarkly and alike.

- supports setting individual feature flag on/off
- supports creating names groups of feature flags and setting default on/off states of individual flags. User than can enable/disable whole group without needing on/off each flag.
- allows advanced settings where user can set different feature flag settings for different sub-domains and domains so the plugin automatically switches between flag setting combinations based on which sub-domain user is accessing.
